# Redbeard Time Tracker for Home Assistant

This public repository contains the Home Assistant metadata and documentation for Redbeard Time Tracker. The application source and container image remain private; no customer data, database, contact details, passwords, or registry credentials are stored here.

## Add this repository to Home Assistant

Use this repository URL as a Home Assistant app repository source:

`https://github.com/itspaulknoll/redbeard-time-tracker-homeassistant`

The private image requires `ghcr.io` registry credentials before installation. See the app documentation for the side-by-side 2.5 migration and registry setup.
